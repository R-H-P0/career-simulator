# 教师篇互动视觉小说设计

## 目标与边界

将现有教师职业的情境问答改为约 20–30 分钟的一学期互动故事，供考虑教师职业的学生探索教师工作的真实取舍。先完整制作教师篇；其他职业维持现状。故事和人物原创，只沿用现有五个观察维度：沟通表达、耐心与共情、课堂管理、临场应变、组织规划。

玩家扮演中国大陆普通初中八年级的入职第一年语文教师，不兼任班主任。作品以日常教学、学生差异、同事协作和家校沟通为题材，不安排严重欺凌或突发安全危机。语气写实克制，不把任一选择写成毫无代价的标准答案。

## 人物与学期主线

常驻角色为三名学生、一名班主任、一名语文组前辈和一名家长。教师篇使用以下角色与动机：

- 林晓舟：愿意发言，容易把个人经历带离课堂问题；并非单纯的“捣乱学生”。
- 周予安：阅读投入，但不愿公开展示未完成的作文；需要具体反馈和自主空间。
- 陈思齐：负责小组事务，重视效率，也会因承担过多任务与同伴产生摩擦。
- 许老师：班主任，了解班级长期情况，与玩家协调职责和家长沟通。
- 赵老师：语文组前辈，提供可参考的教学经验，但不替玩家做决定。
- 林晓舟的母亲：关心孩子的课堂参与，掌握的信息与学校视角不完全一致。

四个阶段共 11 次关键选择，每次固定四个选项，各路线保持 11 次决策：

1. 九月，进入班级：第一次课堂讨论、作文反馈方式、小组阅读任务的起步。
2. 十月，关系显现：未完成作业背后的具体困难、同伴反馈的边界、与班主任核对学生情况。
3. 十一月，合作与压力：阅读展示的分工、准备期的冲突、家长对课堂参与的疑问。
4. 十二月至一月，调整与收尾：检查教学理解、回访个别学生、与同事复盘，最后在同一次学期收尾中看到不同角色的变化。

章节中的具体事件按前面事实改变。例如学生是否主动求助、是否需要教师安排谈话、家长是否先联系学校，以及阅读展示中谁愿意承担任务。变化可以替换或调整后续一两场事件，但主线定期汇合，避免分支数量无限增长。所有路线抵达同一学期收尾；收尾对白和角色状态因历程不同而变化，不标“好结局”或“坏结局”。欠妥选择可通过后续行动补救，但已发生的影响仍会被角色记得。

## 选择与分支规则

每个选项代表一种可理解的工作取舍，包含即时行动、现场回应和可能未解决的事项。四项不得只有一项明显正确、其余三项明显荒谬。选项之间需在沟通时机、学生自主、课堂节奏、事实核对、协作范围等方面形成真实差异。

剧情状态记录具体事实：做过什么、谁得知、谁表达了什么、哪些事情尚未跟进。状态不依赖一个可见的“好感度”替代事实判断；后续条件据此选择事件和对白。场景图须有明确入口、选择出口、汇合点与结尾。回退并重选时，从选点后的选择记录重新计算状态和后续可见剧情，失效的旧答案不再沿用。游玩中不显示关系数值或评分，只由角色反应和后续事件体现影响。

## 画面与交互

采用第一人称电影式场景。玩家教师不露脸，选定台词后有固定主角配音。其他主要角色也使用固定合成音色。人物与背景采用半写实电影插画：日常对白由分层角色、表情、姿态、走位与镜头推拉演出；仅少数关键转折使用短动画镜头。电脑与手机同等重要，分别调整人物构图、字幕框和选项布局。

对白可点击显示完整句子或继续，也可自动播放。选择出现时暂停自动推进。玩家能回看对白、返回并重选。设置提供配音、音乐、环境声的独立音量，以及减弱动画和文字速度控制。字幕始终可见，不能依赖声音传达必需信息。

手动存档提供 8 个档位，列出章节、时间点和剧情摘要；存档在当前设备的浏览器内，不跨设备自动同步。存档保存选择记录与必要版本号，剧情状态由记录重新推导。未手动保存的进度在关闭页面后不保证恢复。存档格式升级或数据损坏时须给出可理解的提示，不能静默覆盖。

## 音频与素材同步

GitHub Pages 托管页面及已制作素材，不在玩家游玩时调用配音生成服务。每句口述对白有稳定台词 ID、对应文本、说话角色和预先生成且审核过的音频。字幕、说话动作和镜头时间以实际音频播放状态为准；卡顿时暂停相关演出。关键特写人工校正动作与口型时点，普通对白只做与声音起止和强弱一致的说话动作，不承诺逐字口型。

玩家首次主动开始后解锁声音。按章节加载必要素材并预取下一场；音频或短镜头加载失败时保留字幕和继续操作。角色立绘、表情与姿态、校园场景、关键短镜头和音效分别管理，可在分支间复用。正式剧本定稿后统计台词量、镜头量与素材清单，再分别估算画面、动画、合成配音和人工校对成本，比较具体制作服务。

## 结果与评分

结果页先展示个人观察报告，再提供学期剧情回顾。保留三类独立结果：

1. **五维行为倾向**：每道选择只记录能观察到的维度，未观察维度不计分。每维显示 0–3 的行为证据均值与观察次数；高低只表示相关做法在本次故事中出现的多少，不等同能力。
2. **情境应对质量**：每个选项按回应当下问题、职责与隐私边界、后续跟进三个标准手工标定 0–3。3 表示相对稳妥但仍有代价，0 表示关键问题被遗漏。普通事件权重为 1；涉及学生隐私或可能留下持续影响的事件权重为 2，权重在剧本评分表中预先固定。关键遗漏另列剧情证据和复盘提示，同时进入该事件质量分。
3. **岗位匹配度参考**：学期后先用剧情化回顾引出工作感受，再用四个明确的 1–5 级问题询问玩家是否愿意持续面对备课、学生差异、课堂组织和家校/同事协作。兴趣分按 `(回答总和 - 4) / 16 × 100` 换算；情境质量分按 `加权质量总分 / 加权满分 × 100` 换算；岗位匹配度参考分为两者等权平均并取整。结果同时展示兴趣和情境质量两个组成分与依据。

0–100 是本作品内的参考分，不写成岗位录用概率或经过验证的适配百分比，也不用于跨职业排名。没有固定 75 分起点。正式发布前检查每题选项的行为证据和质量差异、构造较强与较弱路线、模拟大量可达路线，避免常数输出或分数集中在 85；再用真实试玩反馈检查题意与计分是否一致。未经代表性样本验证时，不宣称预测真实职业表现。

## 验收标准

- 一次通关约 20–30 分钟，固定 11 次关键选择；各路线均可抵达学期收尾。
- 所有四选一场景的选项均有现实动机和代价，关键情节的后果与前文事实一致。
- 回退、更换选择、手动存读档后，不显示与实际选择矛盾的事件、对白或结果。
- 所有口述对白的字幕与音频逐句对应；音频失败、静音和减弱动画时仍可完成体验。
- 手机和电脑均能阅读对白、比较选项、存档和查看报告，无文字遮挡或关键控件重叠。
- 五维证据覆盖足够且有区分度；岗位参考分展示两个组成分，较强与较弱路线有可解释差异，关键风险不会被总均值隐去。

## 实施边界

此设计阶段只确定教师篇。现有 `index.html` 与其他职业内容在设计审阅前不修改。浏览器草图存放于 `.superpowers/brainstorm/`，仅用于讨论布局和画风，不是正式素材。
